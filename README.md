# Hackonet

> Offline-first, peer-to-peer team communication and micro-governance engine built for internet-congested hackathon venues.

## ⚡ Features

* **Local Mesh Transport:** Chat, share code snippets, and vote over Bluetooth LE and local Wi-Fi without internet connectivity.
* **Micro-Decision Engine:** Inline voting cards for instant consensus on tech stacks, feature priority, and task allocation.
* **Hybrid Auto-Fallback:** Uses BLE for low-latency signaling/chat; upgrades dynamically to Wi-Fi Direct/LAN for Git diffs and large payloads.
* **Git & Developer Integrations:** Local Git hook sync and offline-buffered GitHub actions.
* **organization framework:** chat, make dm chats or general chats. fast video communication, dictionary based text communication, split task based on team specialization,
* **encryption facility and time limited chats:** in order to safeguard your privacy, standard encryption system and time dependent chats will be made/
